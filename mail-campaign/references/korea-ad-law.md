# 광고성 판별 — 정보통신망법 제50조

> 이 문서는 판단 보조 자료이며 법률 자문이 아니다. **법 조문 원문(law.go.kr)과 대조하지 못했다.** 2차 해설과 KISA 안내서 요약에 기댄 내용이므로, 실제 광고 발송 전에는 국가법령정보센터의 제50조·시행령 제61조·KISA 「불법스팸 방지를 위한 정보통신망법 안내서」 최신판을 확인한다. (2026-10-29 작성)

## 한 줄 기준

영리 목적의 정보가 **한 줄이라도** 섞이면 메일 전체가 광고성 정보다. 예약·거래 안내 끝에 붙인 "신상품 10% 할인" 한 줄이 메일 전체를 광고로 만든다.

## 광고로 보는 것

- 상품·서비스 소개, 홍보 이미지, 신상품·출시 안내
- 쿠폰·할인·이벤트·적립금·마일리지 안내. 일방적으로 준 쿠폰·적립금의 **발급·소멸 안내도** 광고성으로 본다(2026-03 개정 안내서 보도 기준)
- 영업 목적의 안부 인사, 명절·연말 인사
- 무료 뉴스레터, 가입·생일 쿠폰
- 거래 안내에 덧붙인 다른 상품 추천

## 광고가 아닌 것(거래·운영 안내)

- 예약·신청 확인, 일정·장소 변경 안내
- 계약·거래 내용 안내: 정산·청구·입금 확인, 배송 지연, 품절에 따른 주문 처리 안내
- 등급·포인트·이용 조건 같은 계약 내용 변경 안내
- 리콜·안전 정보, 보안·서비스 점검 안내
- 고객이 요청해서 한 번 보내는 정보

## 경계 예시

| 메일 | 판정 | 이유 |
|---|---|---|
| "신청하신 11/5 워크숍이 확정되었습니다. 장소는 …" | 안내 | 예약 확인 |
| 위 메일 끝에 "다음 달 고급 과정 얼리버드 20% 할인 중" | **광고** | 판촉 한 줄이 섞임 |
| "10월분 납품 대금 청구서입니다. 결제 기한 …" | 안내 | 거래 내용 |
| "할인 적용 후 결제 금액은 45,000원입니다" | 안내(오탐) | 이미 맺은 거래의 금액 설명. 스크립트가 '할인'을 잡으므로 사용자 확인 후 `ad_check_override` |
| "주문하신 원두가 품절이라 대체 원두를 제안드립니다" | 안내 | 주문 처리 |
| 위 메일에 "대체 원두는 특가로 드립니다" | **광고** | 판촉 |
| "적립금 3,000원이 이번 달 말 소멸됩니다" | **광고** | 일방 지급 적립금 소멸 안내 |
| 거래처에 보내는 연말 인사 + 내년 신제품 소개 | **광고** | 안부 + 판촉 |
| 계약 만료일·갱신 조건 안내만 | 안내 | 계약 내용 |

## 광고로 보낼 때 해야 할 것

스크립트가 `kind: 광고` 에서 강제하는 것과 사람이 챙길 것을 나눈다.

| 요건 | 스크립트 |
|---|---|
| 수신자의 명시적 **사전 동의**. 동의 기록이 있는 행만 | 수신동의 열 필수, 동의 값이 아닌 행은 보류 |
| 제목 **맨 앞** `(광고)` | 자동으로 붙인다 |
| 본문에 전송자 명칭·연락처, 수신거부 방법 | `sender_name`·`sender_contact`·`unsubscribe` 필수, 자동으로 붙인다 |
| 수신거부 비용을 받는 사람이 부담하지 않게 | 안내 문구에 포함. 실제 처리 방법은 사람이 정한다 |
| **21시~다음 날 8시** 전송 금지(별도 동의가 없는 한) | plan 이 막고, 발송 중 21시가 되면 멈춘다 |
| 수신거부·동의 철회 뒤 전송 금지 | `수신거부` 로 분류하면 동의 칸이 `거부(날짜)` 가 된다 |
| 동의 여부 정기 확인(2년 주기로 해설됨) | 하지 않는다. 사람이 관리한다 |

사전 동의 예외(해설 기준): 재화 등의 거래로 연락처를 직접 받은 고객에게 거래 종료일부터 6개월 이내에 같은 종류의 재화 광고를 보내는 경우. 이 예외를 쓸지는 사용자가 판단하게 하고, 스킬은 수신동의 열 값만 본다.
