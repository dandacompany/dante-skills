# campaign.md 형식

`init` 이 `assets/campaign.template.md` 를 복사해 만든다. 머리말(`---` 사이)과 본문으로 나뉜다.

## 머리말 키

| 키 | 기본값 | 설명 |
|---|---|---|
| name | (필수) | 캠페인 이름. 중복 방지 키는 `name:이메일` 이다. **발송을 시작한 뒤에는 바꾸지 않는다**(바꾸면 같은 사람에게 다시 나갈 수 있다) |
| source | (필수) | 시트 URL, 시트 ID, 또는 `명단.csv`(캠페인 폴더 기준 상대 경로 가능) |
| tab | 첫 탭 | 시트 탭 이름 |
| kind | 안내 | `안내` 또는 `광고` |
| columns | 자동 | `email=…, name=…, segment=…, consent=…` |
| reply_categories | 확인, 문의, 기타 | 답장 분류. `반송`·`수신거부`는 자동으로 추가된다 |
| interval | 20-30 | 통 사이 간격(초). 범위면 무작위 |
| daily_cap | 400 | 최근 24시간 이 계정 발송 상한 |
| test_to | 보내는 계정 | 테스트 받을 주소 |
| from | 계정 기본 | Gmail 에 등록된 보내는 주소 별칭 |
| html | false | true 면 본문을 HTML 로 보낸다(태그가 없으면 줄바꿈을 `<br>` 로) |
| sender_name · sender_contact · unsubscribe | — | 광고일 때 필수. 본문 끝 표시 문구에 들어간다 |
| ad_check_override | — | 광고성 신호 오탐을 사용자가 확인했을 때만. 사유를 적는다 |

`#` 뒤는 주석이다(값 안에 ` #` 이 필요하면 따옴표로 감싼다).

## 본문

```markdown
# 목적
(자유 서술 — 스크립트는 읽지 않는다. 에이전트와 사람이 읽는다)

## 세그먼트: 확정
제목: {{이름}}님, {{회차}} 참가가 확정되었습니다
본문:
{{이름}}님, 안녕하세요.
...

## 세그먼트: 대기
제목: ...
본문:
...

## 꼬리말
(모든 메일 본문 끝에 붙는다. 선택)
```

- `## 세그먼트: <값>` 의 값은 시트 세그먼트 열의 값과 정확히 같아야 한다.
- `제목:` 은 한 줄이다. `본문:` 다음 줄부터 다음 `##` 제목 전까지가 본문이다.
- `{{열 이름}}` 은 그 행의 시트 값으로 바뀐다. 시트에 없는 열을 쓰면 `check` 가 멈추고, 값이 빈 행은 `보류: 빈 칸(열)` 이 된다.
- 조건문은 없다. 문구가 달라야 하면 세그먼트를 나눈다(분기를 시트 값으로 드러내야 사람이 검토할 수 있다).
- `kind: 광고` 면 렌더할 때 제목 앞에 `(광고) ` 가 붙고 본문 끝에 보내는 곳·연락처·수신거부 안내가 붙는다.
