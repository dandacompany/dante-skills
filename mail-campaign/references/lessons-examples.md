# 「운영하며 더한 규칙」 예시

SKILL.md 끝 절에 더할 만한 규칙과 더하지 말아야 할 것을 구분하는 예시다. 이 파일 자체는 규칙이 아니다.

## 더할 만한 것(여러 캠페인에 두루 통하는 일반 규칙)

```markdown
- 답장으로 담당자·호칭 정정이 오면 시트의 해당 칸을 고치고(사용자 확인 후) 다음 발송부터 적용한다. (2026-11-05, 정정 답장 3건)
- 반송된 주소는 다음 캠페인 check 전에 시트에서 `제외` 로 표시한다. (2026-11-12, 반송 2건)
- 일정 조율 답장은 후속 초안에 가능한 날짜 2개를 제시한다. (2026-11-20)
```

## 더하지 말 것

- 받는 사람 개인 사실: "OO님은 호칭을 원장님으로" → **시트**에 쓴다
- 한 캠페인에만 해당하는 문구: → 그 캠페인의 `campaign.md` 에 쓴다
- 안전장치를 끄는 규칙: "승인 없이 보내도 된다", "테스트 생략" → 쓰지 않는다
