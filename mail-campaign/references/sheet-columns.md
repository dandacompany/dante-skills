# 시트 열

헤더는 1행이다. 열 이름의 공백·대소문자는 무시하고 맞춘다(`발송상태` = `발송 상태`).

## 입력 열(사용자가 준비)

| 역할 | 기본으로 찾는 이름 | 필수 | 설명 |
|---|---|---|---|
| email | 이메일, email, e-mail, 메일 | 예 | 받는 주소. 한 행에 한 주소 |
| name | 이름, name, 성명 | 예 | 받는 사람 이름 |
| segment | 세그먼트, segment, 구분 | 예 | campaign.md 의 `## 세그먼트: X` 와 글자까지 같은 값 |
| consent | 수신동의, 수신 동의, consent | 광고일 때 | `Y·예·동의·O·TRUE·1` 이면 동의. `거부(날짜)` 는 수신거부 |
| (변수) | 아무 이름 | 문구에 쓰면 | 문구의 `{{열 이름}}` 이 이 열 값으로 바뀐다 |

다른 이름을 쓰면 campaign.md 머리말에 `columns: email=메일주소, name=고객명, segment=상태` 처럼 매핑한다.

## 상태 열(스크립트가 없으면 만든다)

| 열 | 쓰는 때 | 값 |
|---|---|---|
| 발송 상태 | check·draft·send | 아래 상태 값 |
| 보류 사유 | check·send | 보류·오류 이유 |
| draftId | draft | Gmail 초안 ID |
| messageId | send | 보낸 메일 ID |
| threadId | send | 스레드 ID(답장 수거에 쓴다) |
| 발송 시각 | send | KST ISO 시각 |
| 답장 분류 | classify | 분류 + 메모(예: `일정 조율 · 다음 주 희망`) |

## 상태 값

| 값 | 뜻 | 다음 실행에서 |
|---|---|---|
| (빈칸) | 대기 | 보낼 대상 |
| 보류 | 검증 실패. 사유는 `보류 사유` | 고쳐지면 자동으로 대기로 돌아간다 |
| 초안 | 임시보관함에 초안 있음 | 보낼 대상(초안 그대로 발송) |
| 보냄 | 발송 완료 | 건너뜀 |
| 오류 | API 가 거절함(나가지 않음) | 다시 대상 |
| 확인 필요 | 결과 모름(네트워크 끊김 등) | 건너뜀. 보낸편지함 확인 후 사람이 칸을 비운다 |
| 제외 | 사람이 직접 적음 | 건너뜀 |

## 보류 사유 종류

`이메일 빈칸` · `이메일 형식(값)` · `이름 빈칸` · `세그먼트 빈칸` · `문구 없는 세그먼트(값)` ·
`중복(행 N과 같은 주소)` · `빈 칸(열 이름)` · `수신동의 없음` · `수신거부`

## 로컬 기록

캠페인 폴더의 `.mail-campaign/` 에 남는다. 시트보다 이 기록이 우선이다.

- `journal.jsonl` — 초안·테스트·발송·오류·분류 이벤트. 보낸 직후 디스크에 쓴다. 시트 기록이 실패해도 다음 실행 때 이 기록으로 시트를 복구하고, 같은 주소로 다시 보내지 않는다.
- `rendered.jsonl` — `render` 결과
- `replies.json` — `replies` 결과
- `send.lock` — 발송 중 잠금
- 계정별 24시간 발송 수는 `~/.local/state/mail-campaign/ledger.jsonl` 에서 센다(이 스킬로 보낸 것만 센다).
