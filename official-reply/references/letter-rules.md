# 회신 공문 표기 요점

rhwp 에는 공문 표기 검수기가 없다. `finish` 는 날짜·시각 꼴만 경고하므로, 나머지는 에이전트가 아래 체크리스트로 직접 본다. 근거는 「행정업무운영 편람」과 「행정 효율과 협업 촉진에 관한 규정 시행규칙」이다(원문 대조는 하지 않았다. 세부는 행정안전부 「행정업무운영 편람」 참조).

## 본문 첫 항목 — 관련 문서 밝히기

```
1. 관련: <보낸 기관> <받은 공문 제목>(<문서번호>, 2026. 10. 27.)
2. 위 호와 관련하여 …을 붙임과 같이 제출합니다.
```

- 받은 공문의 문서번호를 알면 넣는다. 모르면 날짜까지만.
- 요구 사항이 여럿이면 3., 4. 로 항목마다 답한다. 하위 항목은 가., 나. 순서다.

## 날짜·시간·금액

| 쓰기 | 쓰지 않기 |
|---|---|
| 2026. 11. 12.(목) | 2026.11.12, 2026년 11월 12일(목) 혼용 |
| 14:00 | 오후 2시 |
| 금 1,250,000원(금 일백이십오만 원) | 1250000원 |

## 붙임과 「끝.」

- `붙임  <이름> 1부.  끝.` — 마지막 글자 뒤 한 글자(두 타) 띄우고 「끝.」을 쓴다.
- 붙임이 여럿이면 번호를 매기고, 마지막 줄 끝에 「끝.」을 쓴다.
- 붙임은 공문 JSON 의 `붙임목록` 으로 넣는다(SKILL.md 6단계). 견본 붙임 칸 뒤에 「1부.  끝.」이 고정돼 있는지에 따라 스크립트가 부수 표기를 맞춘다.

## 체크리스트(8단계에서 에이전트가 직접 본다)

- [ ] 날짜 「2026. 10. 30.」(점 뒤 띄움, 요일은 「(금)」) · 시각 「14:00」
- [ ] 항목 부호 순서 1. → 가. → 1) → 가) → (1) → (가), 하위 항목은 두 칸 들여쓰기
- [ ] 첫 항목에 관련 문서(보낸 기관·문서번호·날짜·제목)
- [ ] 금액 「금 1,250,000원(금 일백이십오만 원)」
- [ ] 붙임 줄 끝 「끝.」, 부수가 겹치지 않음
- [ ] 수신자·제목·시행번호·시행일이 이번 공문 것(견본 값이 남지 않음)
- [ ] 직인이 「(인)」 자리에 있음, 안 쓴 칸에 빨간 안내문이 없음

## 회신 메일 본문 예시

```
안녕하십니까. <회사명> <담당자>입니다.
<날짜> 보내 주신 「<받은 공문 제목>」 관련 자료를 붙임과 같이 회신합니다.
  - 회신 공문 1부
  - <채운 양식 이름> 1부
확인 부탁드립니다. 문의는 <연락처>로 주시기 바랍니다.
```
