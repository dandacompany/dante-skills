# 회신 공문 표기 요점

kordoc `lint --gate` 가 대부분 잡는다. 여기에는 회신을 쓸 때 자주 틀리는 것만 적는다. 근거는 「행정업무운영 편람」과 「행정 효율과 협업 촉진에 관한 규정 시행규칙」이다(원문 대조는 하지 않았다. 세부는 kordoc `gongmunseo` 스킬 참조).

## 본문 첫 항목 — 관련 문서 밝히기

```
1. 관련: <보낸 기관> <받은 공문 제목>(<문서번호>, 2026. 10. 27.)
2. 위 호와 관련하여 …을 붙임과 같이 제출합니다.
```

- 받은 공문의 문서번호를 알면 넣는다. 모르면 날짜까지만.
- 요구 사항이 여럿이면 3., 4. 로 항목마다 답한다. 하위 항목은 가., 나. 순서다.

## 붙임과 「끝.」

- `붙임  <이름> 1부.  끝.` — 마지막 글자 뒤 한 글자(두 타) 띄우고 「끝.」을 쓴다.
- 붙임이 여럿이면 번호를 매기고, 마지막 줄 끝에 「끝.」을 쓴다.
- 회사 견본 경로(kordoc patch)에서는 두 칸이 한 칸으로 들어간다. kordoc patch 가 연속 공백을 쓰지 못해서다. 두 칸이 꼭 필요하면 한글에서 고친다.
- 일반기안문 서식(gian)에서는 스크립트의 `붙임목록` 으로 넣는다(SKILL.md 6단계).

## 회신 메일 본문 예시

```
안녕하십니까. <회사명> <담당자>입니다.
<날짜> 보내 주신 「<받은 공문 제목>」 관련 자료를 붙임과 같이 회신합니다.
  - 회신 공문 1부
  - <채운 양식 이름> 1부
확인 부탁드립니다. 문의는 <연락처>로 주시기 바랍니다.
```
